🎛️ Soundboard

Klik 1x: play  •  klik lagi: stop  •  klik lagi: ulang dari awal  •  sound bisa numpuk bareng

Kalau tombol tetap tidak bunyi, buka file ini bukan lewat double-click biasa (protokol file:// sering diblokir browser untuk fetch audio), tapi lewat local server. Cara cepat: buka terminal di folder ini, jalankan python3 -m http.server 8000, lalu akses http://localhost:8000/soundboard.html di browser. Cek juga Console (F12) untuk lihat file mana yang gagal dimuat.
